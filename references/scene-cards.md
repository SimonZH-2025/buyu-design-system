# Scene: 小红书图文卡片（3:4）

> 适用于将文章、教程、观点拆解为小红书图文卡片。单个HTML文件包含所有卡片，支持一键导出PNG。

---

## 触发场景

用户说"做图文卡片"、"小红书图文"、"文章转卡片"、"帮我转成图文"、"做卡片"、"转成图文"等。

---

## 📐 卡片规格

| 属性 | 值 |
|------|-----|
| 尺寸 | 1080×1440px（3:4） |
| 最多张数 | 18张（小红书上限） |
| 文件形式 | 所有卡片放一个HTML文件，每张一个 `div.card` |
| 导出方式 | 顶部固定"一键导出PNG"按钮（html2canvas + JSZip 打包为 zip 一次性下载） |
| 浏览器预览 | `transform: scale(0.45); transform-origin: top center; margin-bottom: -792px` |
| 头像必须 base64 内嵌 | **不要用 `<img src="avatar.png">` 外链**——`file://` 直接打开时外链图会让画布被跨域污染、那张卡导不出（少图）。头像一律转成 `data:image/png;base64,...` 内嵌（模板 `template-cards.html` 已内置）。这样双击 HTML 也能导全，不依赖本地服务器 |
| html2canvas / JSZip | 用 CDN 引入，避免本地文件缺失 |

## 📝 排版原则

### 密度控制（核心：内容必须吃满画布）

> 1080×1440 是固定高度，内容少时页面不会自己长满。**绝不能"内容堆上面、下面留空"**。

**① 竖向五分区 + 高度预算**（每页按这个分配高度，不是随便堆）

| 区 | 高度 | 作用 |
|----|------|------|
| 页眉/meta | 56–90px | 期号 / 分类 / 页码 |
| 标题/引言 | 240–420px | 钩子、主张 |
| 证据/正文 | 520–760px | 图 / 账本行 / 图解 / 对比 / 计算面板 |
| 底部条 | 90–180px | 小结 / caption / 金句 |
| 页脚 | 52–86px | 署名 / 页码 |

不是每页都要五区全有，但每页都要有**刻意的竖向构图**。

**② 最低占用率 ≥ 75%**
有效内容（文字+图+数据+色块+装饰大字）必须覆盖画布高度 **≥75%（≥1080px/1440px）**。剩下的留白必须是"设计过的"——leftover 空白不算。

**③ 欠填信号（出现任一条就要改）**
- 表格/账本占画布高度 <45%
- 下方 25% 是空的，且不是"氛围 hero 页"
- 4 个列表项配大片空白
- 正文居中悬在中段，上下没节奏

**④ 内容不够时怎么补（按顺序试，禁止用空白填充）**
1. 加大行高/行距：账本行高拉到 118–170px
2. 加左侧大数字栏（oversized 编号 / 关键词 / 分类标签）
3. 加引用列 / 旁注栏 / 底部 2–3 条小结条
4. 内容只有一句话 → 直接做成「金句大字 hero 页」，让这句话变巨大，而不是小段落
5. 实在撑不满 → **换版式**（别硬撑）

**⑤ 模板自带的填充骨架（直接用，别自己发明）**
`assets/template-cards.html` 已内置三段式结构：每张内容页 = **页眉块 / `.grow` 主体块 / 页脚块**。
- `.card` 是 flex 纵向 + `justify-content: space-between`
- 主体用 `class="grow"`（`flex:1`，吃掉剩余高度，把页脚顶到底）——里面放**真实内容**（账本行/代码面板/卡片），不是空占位
- 这样页眉钉顶、页脚钉底、主体填满中间，自然吃满 1080×1440，下方不会再空

**⑥ 硬禁忌**
- ❌ **禁止用 `<div style="flex:1"></div>` 空占位撑版**（`.grow` 里必须有真实内容）——空占位是"假吃满"，渲染出来就是大片空白。
- ❌ 禁止靠缩小画布、加装饰圆点/光斑来"填空"。内容不够就加大行高/换大字/换版式。

### 变化感
- 每页排版要有变化——不能所有页都一样的layout
- 深色面板页 / 浅色页 / 强调色面板穿插使用
- 大留白页和信息密度页交替

### 绝对禁忌
- ❌ 不要用左侧彩色竖线的卡片
- ❌ 不要用红色圆点前缀
- ❌ 不要千篇一律列表（每项前面一个圆点/数字的平铺排列）
- ❌ 不要HTML默认blockquote样式
- ❌ 不要所有页都用同一种layout

## 🧩 卡片结构模板

### P1 封面
- 大标题（84px）用思源宋体（Noto Serif SC），关键词用红色高亮块（`background: #D8453B; color: #fff; padding: 4px 16px; border-radius: 6px`）
- 副标题（44px）一行显示，紧跟标题下方，`white-space: nowrap`
- 圆形头像（`avatar.png`，120px，`border: 4px solid #F2C53D`）
- 署名「布鱼」44px + 介绍34px
- 整体边框：`border: 28px solid #F2C53D`
- 背景加浅色网格质感（`background-image: linear-gradient(rgba(0,0,0,0.03) 1px, transparent 1px), linear-gradient(90deg, rgba(0,0,0,0.03) 1px, transparent 1px); background-size: 40px 40px`）
- 中间留白区域给用户放效果图/截图

### P2-Pn 内容页
- 根据内容量决定排版密度
- 每页选择不同的排版手法（见下方推荐列表）
- 页码编号用 oversized 淡色装饰数字

### 最后一页 尾页
- 金句（oversized引号装饰 `"` ，DM Serif Display 200px，opacity 0.15）
- 圆形头像 + 署名「布鱼」
- CTA：「关注 布鱼」
- 一行小字 tagline（自定，如「用 AI 把事情做对」）
- ❌ 不要加顶部/底部彩色渐变条（deco-top/deco-bottom）。要分隔用纯色块或单色发丝线

## 🎨 推荐排版手法

从V3验证通过的案例总结，按需组合：

| 手法 | 适用场景 | 要点 |
|------|----------|------|
| 深色面板 | 代码、文件树、重点强调 | 暗色背景(#2A2A33)+亮色文字，圆角16px |
| oversized编号 | 步骤/流程展示 | 极大(64-120px)极淡色(opacity 0.12)做背景装饰 |
| 色块交替行 | 对比/表格 | 暖底行(#F5E9D6) vs 白底行(#fff) 交替 |
| 大箭头流程 | 步骤连接 | 蓝色箭头(48px)连接流程块 |
| 代码面板 | 代码/文件树/命令 | 深色底+Fira Code+三色圆点title bar |
| 金句装饰 | 核心观点/结尾 | oversized引号+白底圆角卡片 |
| 问题→解法对比行 | before/after | 左红底右蓝底，✗ vs ✓ 前缀 |
| 图标+文字横排 | 要点/优势列表 | emoji/icon左对齐+文字说明 |
